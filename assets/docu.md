## .map-Files
Used to load entities at given locations
- Header: RECT for rectangle
- 0: Entity name
- 1: Texture name (0 if the entity should not have a texture)
- 2: X Position
- 3: Y Position
- 4: Width
- 5: Height
- 6: Bounding Box width
- 7: Bounding Box height
- 8: Bounding Box relative X
- 9: Bounding Box relative Y
- 10: X Scale
- 11: Y Scale
- 12: 1/0 if the texture should be repeated
